# Правила работы в демонстрационном личном кабинете

Начните с `SPEC.md`, затем прочитайте `IMPLEMENTATION_PLAN.md` и `docs/architecture.md`.
Для изменения конкретной области сначала найдите ближайший `AGENTS.md` в её папке.

Не расширяйте область задачи без согласования. Перед завершением проверьте контракт,
тесты и пользовательский сценарий, относящийся к изменению.
