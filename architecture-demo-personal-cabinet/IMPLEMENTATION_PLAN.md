# План изменения настройки уведомлений

1. Понять пользовательский сценарий и текущий контракт.
2. Ограничить список изменяемых файлов модулем профиля.
3. Реализовать изменение через API, модель и UI-компонент.
4. Проверить логику, интеграцию, браузерный сценарий и доступность.
5. Передать изменение на независимое ревью вместе с доказательствами.
