# Как доказать готовность

- Unit-проверка подтверждает контракт состояния и компонента.
- Интеграционная проверка подтверждает связку UI, модели и API-клиента.
- Браузерный сценарий подтверждает путь пользователя в профиле.
- Проверка доступности подтверждает подпись, клавиатурное управление и фокус.
