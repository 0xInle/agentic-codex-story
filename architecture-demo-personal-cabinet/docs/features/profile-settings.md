# Спецификация: настройки профиля

Пользователь включает или отключает уведомления на странице профиля. В область
изменения входят API-клиент, модель состояния, переключатель и тесты. Не входят
авторизация, платёжные данные и другие разделы личного кабинета.

Готовый результат сохраняет настройку, показывает понятное состояние и остаётся
доступным с клавиатуры.
