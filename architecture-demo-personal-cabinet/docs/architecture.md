# Границы системы

`apps/web` отвечает за пользовательский интерфейс. `pages` собирают сценарии,
`features` содержат поведение конкретной возможности, а `shared` предоставляет
переиспользуемые компоненты и технические утилиты.

Профиль не обращается к HTTP напрямую из UI: запрос проходит через API-слой,
состояние — через модель, а пользовательское действие — через компонент.
